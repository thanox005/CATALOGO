# Catálogo (repositório do cliente)

Este repositório mostra o catálogo público. Não edite o `index.html`.

## Estrutura
- `index.html`: vitrine (não mexer)
- `dados.json`: preços, textos, coleções e peças (gerado pelo ADM)
- `fotos/`: fotos das peças (geradas pelo ADM)

## Como atualizar
1. Abra o `adm.html` no seu celular ou computador e faça as alterações.
2. Clique em **Exportar dados.json**. O arquivo é baixado.
3. Cada foto enviada no ADM também é baixada, já com o nome certo.
4. No GitHub, entre no repositório e clique em **Add file > Upload files**.
5. Envie o `dados.json` (substituindo o atual) e as fotos para a pasta `fotos/`.
6. Clique em **Commit changes**. Em alguns minutos o catálogo público estará atualizado.

## Observações
- Não renomeie as fotos depois de subir: o `dados.json` aponta para o nome exato.
- Para remover uma peça, exclua-a no ADM e envie o novo `dados.json`.
